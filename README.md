# DiGiComplaints  
This project was a submission for Code-Cubical 3.0 hackathon.
It was an online fourum where people can come and register and create, comment and upvote on issues and all the public data is first segregated ward and district wise and then is summarised with the use of Llama 3 model.  
This summary of public sentiment is then sent wo ward officers and net summary of all wards is sent to the head of the municipal coorperation i.e. the mayor.
